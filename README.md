## Problem

Parkinson's disease causes measurable changes in the voice (tremor, reduced loudness, altered pitch stability) before clinical motor symptoms become severe. The [UCI Parkinson's Voice dataset](https://archive.ics.uci.edu/ml/datasets/parkinsons) (Little et al., 2007) provides 22 acoustic measurements derived from sustained-vowel recordings of 31 subjects (23 with Parkinson's, 8 healthy controls; 195 voice recordings total). The classification task: given the 22 features, predict whether the recording is from a healthy subject (`status = 0`) or someone with Parkinson's (`status = 1`).

## Approach

| Step | Choice | Rationale |
|---|---|---|
| Split | Stratified 80/20 train/test | Preserves class balance (Parkinson's is the majority class at ~75%) |
| Scaling | `StandardScaler` (z-score) | SVM with RBF kernel is sensitive to feature scale |
| Model selection | 5-fold stratified CV, scoring = F1 | Class-imbalanced setting; accuracy would be misleading |
| Search space | `C ∈ {0.1, 1, 10, 100}` × `kernel ∈ {linear, rbf, poly}` × `gamma ∈ {scale, auto}` | Standard SVM tuning grid |
| Baselines | Logistic Regression, Random Forest | Honest comparison; SVM only "wins" if it beats simpler models |

## Run locally

```bash
git clone https://github.com/Sushant-Dagar/Parkinsons-Disease-Detection.git
cd Parkinsons-Disease-Detection

pip install -r requirements.txt

# (Re)train the model — also writes metrics.json
python train.py

# Start the web app
python app.py            # http://127.0.0.1:5000
```

## Run with Docker

```bash
docker build -t parkinsons-detector .
docker run --rm -p 7860:7860 parkinsons-detector
# http://127.0.0.1:7860
```

## Deployment

The simplest free deployment for this Flask + sklearn app is [Hugging Face Spaces](https://huggingface.co/spaces) with the Docker SDK:

2. Push this repo to the Space (it includes `Dockerfile`, `model.pkl`, `app.py`, `templates/`).
3. Spaces builds the image and serves on `https://huggingface.co/spaces/<your-username>/<space-name>`.

## Dataset

Little, M. A., McSharry, P. E., Hunter, E. J., Spielman, J., & Ramig, L. O. (2007). [Suitability of dysphonia measurements for telemonitoring of Parkinson's disease](https://archive.ics.uci.edu/ml/datasets/parkinsons). IEEE Transactions on Biomedical Engineering.

22 features: pitch stability (`MDVP:Fo`, `MDVP:Fhi`, `MDVP:Flo`), jitter measures (`MDVP:Jitter%`, `Jitter:DDP`, …), shimmer measures (`MDVP:Shimmer`, `Shimmer:DDA`, …), harmonics-to-noise ratios (`NHR`, `HNR`), and nonlinear measures (`RPDE`, `DFA`, `spread1`, `spread2`, `D2`, `PPE`).
